# mcp1c — нотатки для розробки

- Розширення 1С у форматі 1C:EDT: `exts/mcp1c`. ТЗ: `docs/TZ.md`; номери пунктів ТЗ згадуються в коментарях коду.
- BSL пишеться з російськими ключовими словами й ідентифікаторами; коментарі в коді — російською; тексти для моделі й користувача (описи інструментів, помилки інструментів) — українською.
- Нові об'єкти метаданих мають префікс `mcp1c_`, додаються в `src/Configuration/Configuration.mdo` і отримують нові UUID.
- Жодних запозичених об'єктів конфігурації і залежностей від БСП: розширення має ставитися на будь-яку конфігурацію.
- Привілейовані модулі в розширеннях недоступні: службові дані розширення читаються за правами ролі `mcp1c_Сервис`; привілейований режим — лише на час виконання запиту до прикладних даних (`mcp1c_ВыполнениеЗапросов`, модель B, ТЗ п. 7.2).
- Об'єкти JSON у коді — `Соответствие` (ключі на кшталт `_meta` і `io.modelcontextprotocol/...` не можуть бути ключами `Структура`).
- Модулі чистої логіки (без `Метаданные`, `Запрос`, регістрів і користувачів ІБ) перелічені в `tests/modules.txt` і покриті тестами OneScript (`tests/unit`). Логіку, яку можна перевірити без платформи, тримати в них.
- Документуючі коментарі — у форматі, який розуміє EDT зі строгою типізацією:
  - посилання `см. Модуль.Функция` — без опису після нього; замість «Структура - см. X» пишеться просто «см. X»;
  - колекції з типом елемента: `Массив из Строка`, `Соответствие из КлючИЗначение`; вкладені колекції EDT не розбирає — `Массив из Произвольный`;
  - у `X из A, B` тип B належить елементам колекції, тому інші типи ставляться перед колекцією: `Неопределено, Массив из Строка`;
  - «структура або Неопределено» — багаторядково, `- Неопределено` першим рядком, потім `- Структура:` зі властивостями;
  - EDT виводить типи властивостей повернених структур з коду і порівнює з описом: значення з JSON і запитів, оголошені точним типом, приводяться до нього (`Строка()`, `Число()`, `= Истина`), без `Мин`/`Макс`; `Произвольный` в описі збігається лише зі значенням невідомого типу;
  - у приватних методах — однорядковий коментар усередині тіла, повний опис — коли метод повертає структуру.
- Перед комітом:
  - `python tools/check_metadata.py exts/mcp1c`
  - `cd tools/bsl-syntax && npm ci && node check.mjs ../../exts/mcp1c/src`
- CI на кожен PR додатково запускає тести OneScript і BSL Language Server; якщо мережа середовища не пускає до NuGet, Maven і релізів GitHub, їх результат дивитися в CI.
- Проєкт в EDT (робоча область користувача, проєкт `mcp1c`) має давати 0 проблем у діагностиці, зокрема строгої типізації.
- Перевірка розгорнутого сервера: `python tools/mcp_smoke_test.py --url <ендпоінт> --token <PAT>`.
