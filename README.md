# mcp1c — MCP-сервер для 1С:Підприємство 8.3

Розширення конфігурації, яке відкриває дані будь-якої бази 1С/BAS для AI-клієнтів (Claude, ChatGPT, Cursor, локальні моделі) за протоколом [Model Context Protocol](https://modelcontextprotocol.io/specification/2026-07-28).

- **Лише читання.** Жодних записів, проведення чи довільного коду.
- **Доступ за токеном з терміном дії** і миттєвим відкликанням; OAuth 2.1 для веб-конекторів — на етапі 3.
- **Права за профілем клієнта:** об'єкти, поля, рядки, маскування, ліміти обсягу.
- **Універсальність:** без запозичених об'єктів і без залежності від БСП; знання про дані береться з метаданих під час виконання.

Повне технічне завдання: [docs/TZ.md](docs/TZ.md).

| 1. Ядро і безпечне читання | Клієнти й профілі доступу, глобальні заборони, 9 інструментів читання, аудит у регістрі, адмін-форми | — |
