## Не перевірено й відкриті питання

- **Навантаження з 10 паралельними клієнтами на клієнт-серверній базі** (MS SQL або PostgreSQL) — ціль ТЗ п. 10.1.
- **Відповіді моделі в Claude Code** (потрібен `/login`); Cursor і VS Code.
- **IP клієнта від реального проксі** (`X-Real-IP`), шаблони nginx і IIS.
- **Мінімальна цільова платформа.** Перевірено лише 8.3.27.
- **Б9 (обмеження рядків за організацією)** перевірено на BAS ERP на етапі 2, на УТ і УТП не повторювалося.
- **Разовий HTTP 500.** Один раз приблизно з 3 000 викликів платформа повернула HTTP 500 «Тип не визначений '8de07304-…'» — це тип менеджера регістра `mcp1c_НастройкиСервера`. Помилка була на першому виклику прогону, одразу після запису профілю й видачі токенів через зовнішнє з'єднання. Запису в журналах реєстрації ERP, УТ і УТП немає, повторно не відтворилася.
